# AutoDB card for AutoDoc protocol 6

This AutoDB plugin update requires **AutoDoc v0.1.54 or newer**. Earlier AutoDoc
versions speak at most plugin protocol 5 and refuse the updated manifest, so
update AutoDoc before installing this AutoDB plugin release.

The card now selects visible connection and tree rows on a left click and moves
through the list with the wheel. Its cursor uses the same active and inactive
highlight colors as the results table. To reopen a hidden card, use **SPC p ›
AutoDB › o** or **Plugins › AutoDB › Reopen card**; the running connection and
results remain available.
